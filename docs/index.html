1 Hiểu Nhanh: Phần Mềm Này Gồm Những Gì?

Hệ thống có 2 thành phần tương ứng với 2 vị trí lắp đặt tại bệnh viện:

Thành phần Vị trí lắp đặt File thực thi cần có Nhiệm vụ chính
1. Máy Chủ Gateway Server Đặt tại phòng Server / IT Bệnh viện TTSG_DicomGateway_Setup_v2.0.exe Chạy dịch vụ ngầm 24/7, nhận ảnh từ máy khám, đóng gói thành chuẩn DICOM quốc tế và gửi vào PACS / lấy danh sách từ RIS Worklist.
2. Máy Trạm Phòng Khám Đặt tại phòng Siêu âm, Nội soi, Điện tim, X-quang... Cách A (Dễ nhất): Mở Web Chrome
Cách B: File client_agent.exe 		Bác sĩ/KTV chọn ca bệnh, kéo ảnh/PDF kết quả vào rồi bấm "Đẩy PACS". Hoặc Client Agent tự quét thư mục xuất ảnh của máy khám để gửi ngầm.

2 Làm Sao Để Có File .EXE Cài Đặt? (Sử Dụng Các File .bat)

Để tạo ra các file .exe mang đi cài đặt ở bệnh viện, bạn thực hiện theo đúng 4 bước đơn giản dưới đây ngay trên máy tính của bạn:

🛠️
Khâu Chuẩn Bị (Chỉ làm 1 lần duy nhất trên máy phát triển của bạn): 1. Máy đã cài Python 3.10+ (Khi cài nhớ tick chọn ô Add Python to PATH).
2. Cài phần mềm miễn phí Inno Setup 6 (Tải tại: jrsoftware.org/isdl.php, cứ bấm Next → Next → Install là xong).
👉 QUY TRÌNH 4 BƯỚC ĐÓNG GÓI RA FILE .EXE
  • 1
    Khởi tạo môi trường thư viện (Nếu là lần đầu chạy dự án)
    Tìm và nhấp đúp chuột (Double-click) vào file:
    👉 setup.bat

    • File này sẽ tự động tạo thư mục .venv và tải toàn bộ thư viện cần thiết.
    • Khi chạy xong, màn hình console báo: === Cai dat xong ===. Bạn bấm phím bất kỳ để đóng.

  • 2
    Tạo file cài đặt Server 1-Click (Setup.exe cho máy chủ)
    Tìm và nhấp đúp chuột (Double-click) vào file:
    👉 build_setup_installer.bat

    • Kịch bản sẽ tự động chạy build_server_exe.bat để biên dịch mã nguồn Backend, sau đó Inno Setup tự nén lại thành 1 file duy nhất.
    • KẾT QUẢ ĐẠT ĐƯỢC: Xuất hiện file cài đặt nằm tại:
    📁 dist\TTSG_DicomGateway_Setup_v2.0.exe (~18 MB).
    👉 Đây là file bạn copy vào USB để mang đi cài đặt ở máy chủ bệnh viện!

  • 3
    Tạo file chạy cho máy trạm phòng khám (Client Agent)
    Tìm và nhấp đúp chuột (Double-click) vào file:
    👉 build_client_exe.bat

    • Kịch bản sẽ tự động đóng gói ứng dụng theo dõi thư mục phòng khám thành file độc lập.
    • KẾT QUẢ ĐẠT ĐƯỢC: Xuất hiện file nằm tại:
    📁 dist\client_agent.exe (~10 MB).
    👉 File này dùng cho các máy khám cần tự động quét ảnh ngầm mà không cần mở web.

  • 4
    Tạo file bản vá nâng cấp khi có tính năng mới (.pkg)
    Tìm và nhấp đúp chuột (Double-click) vào file:
    👉 build_patch.bat

    • Kịch bản sẽ hỏi bạn số phiên bản (Ví dụ gõ: 2.1.0) → Nhấn Enter.
    • KẾT QUẢ ĐẠT ĐƯỢC: Xuất hiện file bản vá:
    📁 TTSG_Gateway_Patch_v2.1.0.pkg.
    👉 Gửi file này cho bệnh viện để họ cập nhật trực tiếp trên Web trong 3 giây.

2.1. Bảng Tổng Hợp Vai Trò Của Các File .bat Trong Thư Mục Gốc

Tên file .bat Ai sử dụng? Thao tác thực hiện Mục đích & Kết quả
setup.bat Người phát triển Nhấp đúp chuột Cài đặt môi trường ảo .venv và tải toàn bộ thư viện Python.
build_setup_installer.bat Người phát triển Nhấp đúp chuột Tạo ra file cài đặt hoàn chỉnh: dist\TTSG_DicomGateway_Setup_v2.0.exe.
build_server_exe.bat Hệ thống gọi tự động Được gọi bởi build_setup Biên dịch mã nguồn Server thành thư mục nhị phân dist\TTSG_DicomGateway\.
build_client_exe.bat Người phát triển Nhấp đúp chuột Tạo ra file máy trạm: dist\client_agent.exe.
build_patch.bat Người phát triển Nhấp đúp chuột Tạo file bản vá nâng cấp: TTSG_Gateway_Patch_vX.X.X.pkg.
run.bat Người kiểm thử Nhấp đúp chuột Khởi chạy Server trực tiếp dưới dạng mã nguồn Python (để test nhanh).
test_ket_noi_pacs.bat Kỹ sư triển khai Nhấp đúp chuột Kiểm tra kết nối C-ECHO tới máy chủ PACS xem có thông mạng không.

3 Triển Khai Tại Bệnh Viện Mới (Site Deployment)

Sau khi đã có file TTSG_DicomGateway_Setup_v2.0.exe ở Bước 2, bạn mang file này sang máy chủ của bệnh viện để tiến hành cài đặt:

👉 CÀI ĐẶT MÁY CHỦ BỆNH VIỆN TRONG 3 BƯỚC
  • 1
    Chạy File Cài Đặt Setup.exe
    Nhấp đúp chuột vào file TTSG_DicomGateway_Setup_v2.0.exe → Bấm Next → Bấm Next → Bấm Install → Bấm Finish (Mất 10 giây).

    Phần mềm tự động cài vào C:\Program Files\TTSG DICOM Gateway, tự đăng ký Windows Service chạy ngầm 24/7 và tự mở cổng tường lửa Firewall.

  • 2
    Điền Thông Số PACS & RIS Trên Giao Diện Web
    Trình duyệt web sẽ tự động mở trang: http://localhost:5000.

    • Đăng nhập tài khoản: trind / mật khẩu: admin123.
    • Vào Tab ⚙️ Cấu Hình → Điền IP, Port, AE Title của PACS và RIS theo thông tin IT Bệnh viện cung cấp → Bấm 💾 Lưu Cấu Hình.
    • Bấm nút 🔍 Test PACS và 🔍 Test RIS → Nhận thông báo 🟢 Kết nối Thành Công.

  • 3
    Cấu Hình 2 Card Mạng Trên Máy Chủ (Dual-NIC)
    Đảm bảo an toàn cách ly theo đúng quy tắc kỹ thuật sau:
    Card mạng Cắm vào mạng nào? Địa chỉ IP ví dụ Default Gateway
    Card 1 (NIC 1) Mạng phòng khám 192.168.0.3 192.168.0.1
    Card 2 (NIC 2) Mạng nội bộ PACS/RIS 192.168.6.200 ĐỂ TRỐNG (BLANK)

3.1. Thiết Lập Cho Các Máy Phòng Khám (Siêu Âm / Nội Soi / Điện Tim)

Tại máy tính ở các phòng khám, Kỹ thuật viên không cần cài đặt phần mềm phức tạp:

  1. Mở trình duyệt Google Chrome hoặc Edge, gõ địa chỉ: http://192.168.0.3:5000 *(Thay bằng IP máy Gateway Server)*.
  2. Nhấp chọn đúng phòng của mình (Ví dụ: 🩺 Phòng Siêu âm 01).
  3. Tick chọn: "☑️ Ghi nhớ nơi làm việc trên máy này" → Bấm "🚀 Vào Làm Việc Ngay" (Không cần gõ mật khẩu).
  4. Tạo lối tắt (Shortcut) ra màn hình Desktop để lần sau bấm 1 cái là vào thẳng trang làm việc!

4 Cấp Phát & Quản Lý Bản Quyền Thương Mại

👉 3 BƯỚC KÍCH HOẠT BẢN QUYỀN
  • 1
    Lấy Mã Máy Tính (Hardware ID)
    Trên Web Admin của khách hàng (http://localhost:5000) → Chọn Tab 🔑 Bản Quyền & Hệ Thống → Bấm nút [📋 Sao Chép] tại mục Mã Hardware ID (Ví dụ: TTSG-6F6E-BCA7-82EA-C52B).
  • 2
    Tạo File Bản Quyền license.key (Làm trên máy của bạn)
    Mở cửa sổ dòng lệnh PowerShell/CMD trên máy bạn, chạy lệnh sau: 
    python license_generator.py --customer "Bệnh viện Đa khoa Tâm Trí Sài Gòn" \
                           --hwid "TTSG-6F6E-BCA7-82EA-C52B" \
                           --exp "2035-12-31" \
                           --modalities "US,ES,ECG,CR,DR,BD,PFT" \
                           --stations 50 \
                           --out "license.key"
  • 3
    Kích Hoạt Trên Web Khách Hàng
    Tại Tab Bản Quyền → Kéo thả file license.key vào ô tải lên → Bấm nút "🔑 Kích Hoạt Bản Quyền Ngay" → Màn hình báo 🟢 Bản Quyền Hợp Lệ (Enterprise Edition) là hoàn tất nghiệm thu!
⏱️
Quy Định Bản Dùng Thử (Demo Trial 30 Ngày):
• Khi cài đặt mới trên máy chủ mà chưa có license.key, hệ thống tự động kích hoạt chế độ Dùng Thử 30 Ngày (1 tháng) với đầy đủ tính năng.
• Màn hình Web sẽ hiển thị thanh tiến trình đếm ngược 30 ngày (Timeline Progress Bar).
• Sau 30 ngày nếu chưa nhập mã bản quyền, hệ thống sẽ chuyển sang trạng thái 🔴 EXPIRED và yêu cầu nạp file bản quyền thương mại để tiếp tục đẩy dữ liệu.

5 Cập Nhật Khi Có Phiên Bản Mới (.pkg Patch)

Khi công ty phát hành bản vá sửa lỗi hoặc thêm chức năng mới, bạn chỉ cần làm 2 bước:

  1. Phía Công Ty: Chạy file build_patch.bat → Gõ số phiên bản mới (Ví dụ: 2.1.0) → Tạo ra file TTSG_Gateway_Patch_v2.1.0.pkg → Gửi file này cho bệnh viện qua Zalo/Email.
  2. Phía Bệnh Viện: IT Bệnh viện vào Web http://localhost:5000 → Tab 🔑 Bản Quyền & Hệ Thống → Chọn file TTSG_Gateway_Patch_v2.1.0.pkg → Bấm "🚀 Cập Nhật Ngay".
🛡️
Cập Nhật Trong 3 Giây & Tuyệt Đối An Toàn Hệ thống tự động giải nén và cập nhật mã máy mới ngay tức thì. Toàn bộ file cấu hình kết nối PACS, CSDL bệnh nhân và thông tin bản quyền được bảo toàn 100%, không bị mất.

6 Hướng Dẫn Kỹ Thuật Viên Vận Hành Hàng Ngày

Giao diện Web được thiết kế tối giản, thân thiện với 4 bước thao tác dễ dàng:

👉 THAO TÁC 1-CHẠM CỦA KỸ THUẬT VIÊN
  • 1
    Bước 1: Mở Tab "📋 RIS Worklist"
    Hệ thống tự động hiển thị danh sách bệnh nhân chờ khám từ RIS. Bác sĩ/KTV nhấp nút màu xanh `🩺 Thực hiện CLS` tại tên bệnh nhân.
  • 2
    Bước 2: Tự Động Chuyển Sang Tab 3 & Nạp Thông Tin
    Hệ thống tự động điền 100% thông tin bệnh nhân (Mã BN, Họ tên, Ngày sinh, Số chỉ định) mà không cần gõ lại bằng tay.
  • 3
    Bước 3: Kéo Thả File Kết Quả & Chọn Report Chính
    Kéo thả file PDF kết quả và các file ảnh JPG/PNG vào ô đính kèm. Nhấp chọn nút radio `⭐ [Report chính]` cho file phiếu kết quả chính.
  • 4
    Bước 4: Bấm "🚀 ĐẨY LÊN PACS NGAY"
    Hệ thống tự đóng gói chuẩn DICOM và gửi sang PACS Server. Cột Report của ca khám trên phần mềm xem ảnh PACS Viewer lập tức sáng đèn!

7 Sửa Các Lỗi Thường Gặp Khi Triển Khai

Hiện tượng Nguyên nhân Cách xử lý nhanh nhất
Bấm "Test PACS" báo lỗi Timeout PACS chưa mở quyền cho IP của máy Gateway Nhắc IT Bệnh viện vào PACS Server, thêm 1 DICOM Node mới: AE Title DICOM_GATEWAY, IP là IP Card mạng số 2 của máy Gateway.
Máy phòng khám không vào được địa chỉ Web Tường lửa Windows Firewall máy chủ chặn cổng 5000 Chạy lại file service_install.bat bằng quyền Run as Administrator để script tự động mở cổng Firewall.
Chạy build_setup_installer.bat báo lỗi thiếu Inno Setup Chưa cài phần mềm Inno Setup 6 trên máy phát triển Tải và cài đặt Inno Setup 6 từ trang jrsoftware.org (bấm Next Next Install) rồi chạy lại file .bat.
Tài khoản Admin bị khóa 5 phút Gõ sai mật khẩu quá 5 lần Mở services.msc → Chuột phải vào dịch vụ TTSG_DicomGateway → Chọn Restart để mở khóa ngay lập tức.
