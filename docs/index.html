Xây Dựng Nghiệp Vụ, Không Lo Hạ Tầng

Chuyển đổi hình ảnh và báo cáo cận lâm sàng thành chuẩn y tế DICOM hoàn chỉnh. Toàn bộ cơ chế kết nối mạng, chuyển phát hàng đợi, thử lại tự động và bảo mật được giải quyết trọn vẹn.

C-STORE PACS Push

Đẩy hình ảnh trực tiếp lên hệ thống lưu trữ hình ảnh y tế PACS qua giao thức DICOM tiêu chuẩn (DIMSE C-STORE).

Port: 104 / 11112 | SOP: Secondary Capture

RIS Worklist C-FIND

Truy vấn danh sách chỉ định bệnh nhân chờ thực hiện trực tiếp từ máy chủ RIS/HIS, tự động điền metadata.

Query Tag: (0040,0100) Scheduled Procedure

PDF Encapsulation

Đóng gói tài liệu báo cáo kết quả PDF thành đối tượng DICOM Encapsulated PDF (SOP 1.2.840.10008.5.1.4.1.1.104.1).

Encapsulated Document: 100% Vector PDF

Image Transcoding

Chuyển đổi hình ảnh JPG/PNG độ phân giải cao thành ảnh DICOM y khoa với thang độ xám (MONOCHROME2) hoặc RGB màu.

Color Space: RGB 24-bit / Grayscale 8-bit

Multi-Station Watcher

Tự động giám sát nhiều thư mục xuất file của máy siêu âm, nội soi, điện tim trong mạng nội bộ bệnh viện.

Polling Rate: 3.0s | Debounce Lock: True

RSA 2048-bit Licensing

Khóa bản quyền theo phần cứng máy tính (Hardware ID), chống sửa đổi và bảo vệ quyền sở hữu trí tuệ tuyệt đối.

Sign Algorithm: RSA-SHA256 PKCS#1 v1.5
Khả Năng Tích Hợp

Một Chuẩn Kết Nối. Cho Mọi Hệ Thống HIS / RIS.

Tương thích với mọi ngôn ngữ lập trình phổ biến qua giao diện RESTful API chuẩn mực.

import requests

url = "http://localhost:8088/api/upload-manual"
files = [
    ('files', ('sieu_am_bung.jpg', open('sieu_am_bung.jpg', 'rb'), 'image/jpeg')),
    ('files', ('ket_qua.pdf', open('ket_qua.pdf', 'rb'), 'application/pdf'))
]
payload = {
    'patient_id': 'BN20260831001',
    'patient_name': 'NGUYEN VAN A',
    'accession_number': 'CD26083199',
    'study_description': 'Siêu âm ổ bụng tổng quát',
    'modality': 'US',
    'main_report_filename': 'ket_qua.pdf'
}

response = requests.post(url, data=payload, files=files)
print(response.json())

Sổ Tay Đóng Gói, Triển Khai & Cài Đặt Chi Tiết

Quy trình chuẩn hóa từ A-Z để bất kỳ kỹ sư IT hay nhân viên triển khai nào cũng có thể thực hiện thành công.

CHƯƠNG 1

Cách Đóng Gói Phần Mềm Thành File Chạy Độc Lập (.exe)

Phần mềm được đóng gói hoàn toàn tự động thông qua script batch script chuẩn hóa, không cần cài đặt Python trên máy khách hàng.

  • 1
    Kích hoạt file đóng gói Server: Nhấp đúp chuột vào file build_server_exe.bat tại thư mục gốc của dự án. Script sẽ tự động dọn dẹp thư mục build cũ và gọi PyInstaller để đóng gói thành dist/TTSG_DicomGateway/TTSG_DicomGateway.exe.
  • 2
    Tạo bộ cài đặt trọn gói Setup (.exe Installer): Nhấp đúp chuột vào file build_setup_installer.bat. Script sẽ biên dịch tệp installer.iss qua Inno Setup Compiler để tạo file Setup_TTSG_DicomGateway_v2.0.exe có hỗ trợ tạo shortcut Desktop và cài Windows Service tự động.
  • 3
    Đóng gói Client Agent cho máy trạm: Vào thư mục Client/ và chạy build_client_exe.bat để tạo file TTSG_ClientAgent.exe phục vụ gửi file tự động từ các máy trạm phòng khám.
CHƯƠNG 2

Triển Khai & Cấu Hình Chi Tiết Cho 1 Site Bệnh Viện / Phòng Khám Mới

Các bước thực hiện khi đưa Gateway vào vận hành tại cơ sở y tế mới:

  • 1
    Cài đặt phần mềm: Chạy file Setup_TTSG_DicomGateway_v2.0.exe dưới quyền Administrator. Mặc định cài vào C:\TTSG_Dicom_Gateway.
  • 2
    Cấu hình Thông Số Kết Nối PACS: Truy cập Web Admin tại http://localhost:8088. Vào Tab Kết Nối PACS / RIS, nhập IP máy chủ PACS, Port (thường là 104 hoặc 11112), Called AE Title (PACS Server) và Calling AE Title (TTSG_GATEWAY). Nhấp C-ECHO PACS để kiểm tra thông tuyến.
  • 3
    Cấu hình RIS Worklist Server (Tùy chọn): Tích chọn "Kích hoạt RIS Worklist", nhập thông số IP/Port của máy chủ RIS để cho phép kỹ thuật viên tra cứu danh sách chỉ định bệnh nhân trực tiếp.
  • 4
    Thiết lập Thư Mục Theo Dõi (Watch Folders): Vào Tab Thư Mục Quét, thêm các đường dẫn thư mục xuất ảnh từ máy siêu âm, nội soi, điện tim (ví dụ: D:\Export\SieuAm, D:\Export\NoiSoi) kèm Modality tương ứng.
  • 5
    Đăng ký Chạy Ngầm Windows Service: Nhấp đúp chuột vào service_install.bat dưới quyền Administrator. Gateway sẽ tự động khởi động cùng Windows mà không cần đăng nhập user.
CHƯƠNG 3

Cấp Phát & Quản Lý Bản Quyền Phần Mềm (RSA 2048-bit)

Hệ thống hỗ trợ cơ chế dùng thử 30 ngày tự động và kích hoạt bản quyền vĩnh viễn khóa cứng theo phần máy tính:

  • 1
    Lấy Mã Phần Cứng (Hardware ID): Trên giao diện Web Admin, vào Tab Bản Quyền. Nhấp nút Sao Chép tại ô Mã Máy (Ví dụ: TTSG-6F6E-BCA7-82EA-C52B).
  • 2
    Tạo File License.key từ phía Nhà Phát Triển: Kỹ sư hệ thống sử dụng script license_generator.py với khóa Private Key RSA 2048-bit:
    python license_generator.py --hwid TTSG-6F6E-BCA7-82EA-C52B --customer "BV Tam Tri Sai Gon" --exp PERMANENT --modalities ALL --stations 50
  • 3
    Kích hoạt Bản Quyền: Gửi file license.key cho bệnh viện. Tại Tab Bản Quyền, kéo thả file vào khung nạp bản quyền hoặc dán nội dung chuỗi ký tự rồi nhấp Kích Hoạt Bản Quyền Ngay.
CHƯƠNG 4

Đóng Gói & Gửi Cập Nhật Bản Vá Cho Site Mỗi Khi Có Phiên Bản Mới

Quy trình nâng cấp không làm gián đoạn cấu hình hiện tại của bệnh viện:

  • 1
    Tạo Gói Bản Vá (.pkg): Chạy file build_patch.bat. Hệ thống sẽ tự động nén các file code/template/static được cập nhật và ký số RSA 2048-bit vào tệp TTSG_Gateway_Patch_vX.X.X.pkg.
  • 2
    Nạp Bản Vá Trực Tuyến: IT bệnh viện đăng nhập vào Web Admin, vào mục Cập Nhật Hệ Thống (Hot-Patch), chọn file .pkg và nhấp Cập Nhật Ngay. Gateway sẽ tự động giải nén, ghi đè và khởi động lại dịch vụ trong vòng 2 giây.

Giải Đáp Thắc Mắc Triển Khai

1. Máy tính trạm có cần cài đặt phần mềm phức tạp không?
Không. Kỹ thuật viên chỉ cần mở trình duyệt web (Chrome, Edge, Cốc Cốc) truy cập địa chỉ IP máy chủ Gateway (ví dụ: http://192.168.1.100:8088) để thực hiện ca khám, hoặc cài đặt TTSG_ClientAgent.exe siêu nhẹ chỉ chiếm 15MB RAM nếu muốn tự động quét thư mục ảnh nền.
2. File kết quả PDF có bị mờ hoặc vỡ chữ khi đẩy lên PACS không?
Không bao giờ. TTSG DICOM Gateway sử dụng chuẩn Encapsulated Document nguyên bản, nhúng toàn bộ luồng vector của file PDF vào DICOM tag (0042,0011). Khi mở trên eFilm, Radiant DICOM Viewer hay PACS Web Viewer, toàn bộ chữ và hình ảnh đều sắc nét 100% như file PDF gốc.
3. Khi mất kết nối mạng với PACS Server, dữ liệu có bị mất không?
Hoàn toàn không. Gateway tích hợp sẵn cơ chế hàng đợi trung chuyển (Store-and-Forward) và lưu trạng thái vào cơ sở dữ liệu SQLite. Khi mạng bị đứt, các ca khám sẽ được chuyển sang trạng thái RETRYING và tự động gửi bù ngay khi PACS phục hồi kết nối.
4. Làm sao để nâng cấp phần mềm khi có tính năng mới?
Bạn chỉ cần nhận file bản vá .pkg từ nhà phát triển và nạp trực tiếp qua Web Admin mục "Cập Nhật Bản Vá". Toàn bộ cấu hình mạng, tài khoản và lịch sử ca khám đều được giữ nguyên 100%.
